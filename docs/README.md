# Key Vault documentation

Key Vault is where a media team adds every stream destination for an event, and where everyone can see whether each one is really working. Pick the page that matches what you are doing.

## If you add or check destinations

- [User guide](1-user-guide.md): add a destination, replace a link, and what **Live**, **Unstable**, **Problem** and **Not set up yet** mean.
- [Install Key Vault as an app](2-install-as-app.md): open it in its own window from Chrome, Edge or a phone.

## If you run it for a team

- [Setting up Key Vault](3-setup.md): Supabase, Google sign-in, Vercel and connecting bunryu, in order, with a check after each step.
- [The bunryu link](5-bunryu-contract.md): how the streaming server reports each output and how that becomes a status.
- [Security](6-security.md): what to set up before you go live (sign-in limits, two-step verification, secrets), what Key Vault does not do, and the rules for changing it safely.

## If you change the code

- [Development](4-development.md): run it locally, the checks, and the project structure.
